# Void_Refractions

Abandoned. Alone. Adrift. Drawn towards a star that shouldn't exist.
A scientist wakes up from suspended animation (sleep) in an empty spaceship some time after an unexplained event caused disappearance of the other crewmembers.

## How to Play
WSAD movement
E: interact with objects
left-mouse: pickup and and set down objects
